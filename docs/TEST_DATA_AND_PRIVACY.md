# Test Data and Privacy

- All identities and financial records are synthetic.
- Unique values are generated for each test to prevent collision and order dependence.
- Tests own cleanup of created records.
- Credentials in `.env.example` are local demo credentials, not secrets.
- Real employer domains, endpoints, tokens, customer data, screenshots, and proprietary rules are prohibited.
- CI artifacts must be reviewed before public retention to ensure they contain no unexpected sensitive content.
